#Actividad1: Juego pintando

#Descripción:
Programa basado en herramienta de dibujo interactivo en python.

Implementaciones:
-Seleccion de color: Se añadio un color nuevo a la paleta disponible.

-Trazado de circulos: Se agrego la función que permite la creacion de circulos a partir de puntos de clic.

-Dibujo de rectangulos: Al marcar un punto inicial y final en diagonal se dinuja y rellena el rectangulo.

-Dibujo de triangulos: Basada en la seleccion de dos puntos se crea un triangulo que se rellena.

Requisitos:
Libreria "freegames"

#Ejecucion:
python3 paint.py
